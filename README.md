### Shopfloor da Confeção

Shopfloor da confeção é uma aplicação web desenvolvida em React.js e uma API construída NODE.js.

# Instalação
## Pré-requisitos
Antes de começar, é preciso ter o Node.js instalado.

# Clone o repositório
git clone https://github.com/seu-usuario/nome-do-repositorio.git

# Instalando as dependências
PARA INICIAR O FRONTEND:
Na pasta raíz do projeto: "shopfloor"

1. npm install
2. npm start

PARA INICIAR O BACKEND:
Na pasta raíz do projeto: "shopfloor"

1. cd api
1. npm install
2. npm start
